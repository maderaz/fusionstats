How to read this page (humans & design agents) click to collapse

This page is engineered to be crawled. Read whichever surface suits you:

  • Fast path — parse the JSON. The complete spec (tokens + every component, variant & state) is embedded as <script type="application/json" id="fusion-ui-kit"> at the bottom of the document. One fetch → full data relay.
  • DOM path — read the attributes. Every element is live in the DOM and self-describing via data-* attributes. No screenshots required; the rendered node is the spec.
  • Human path — look & copy. Each element is rendered in every state, with a spec table and a copy-paste HTML snippet.

DOM attribute schema:

AttributeApplied toMeaning
data-component<article>Component family, e.g. button, deposit-area, icon.
data-variant<article>Variant within the family, e.g. primary, tertiary, primary-arrow.
data-figma<article>Source Figma node id (traceability back to the design file).
data-staterendered elementThe exact state this instance shows: default, hover, clicked, typing, typed, disabled.
data-tokenswatch / valueThe design-token name a value maps to, e.g. color.purple, radius.btn.

Deposit Area

574:63input group

The amount-entry field for deposits (Figma "Typing area"). 310 × 128, radius 12. It carries six states across the entry lifecycle — from resting, through focus and typing, to a committed value. The focus states (Clicked / Typing) switch the stroke to the brand purple; the resting states use the neutral stroke.
