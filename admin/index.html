The log isn't set up yet

The beacon writes to a private GitHub gist. Two one-time steps:

  1. Create a secret gist at gist.github.com with one file, traffic-log.json, holding {"entries":[]}. Its id is the long hex part of its address.
  2. Create a fine-grained token at github.com/settings/tokens with Gists: read and write, then add to Vercel (Project Settings → Environment Variables): 
    GITHUB_TOKEN = the token
GIST_ID      = the gist's id
    and redeploy. Visit any page once, then refresh this one.
