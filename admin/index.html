Storage not configured

The traffic logger uses a private GitHub Gist as storage. Two one-time steps:

  1. 1 Create a secret gist at gist.github.com with one file named traffic-log.json containing exactly: 
    {"entries":[]}
    Click Create secret gist. Copy the gist id from the URL — it's the long hex segment after your username (https://gist.github.com/<you>/abc123…).
  2. 2 Create a fine-grained personal access token at github.com/settings/tokens with scope Gists: read and write. No repo access needed.
  3. 3 In Vercel → Project Settings → Environment Variables, add (Production + Preview + Development): 
    GITHUB_TOKEN  = ghp_…   (the PAT)
GIST_ID       = abc123…  (the gist id)
  4. 4 Trigger a redeploy (Deployments → Redeploy on the latest one, or push any commit).
  5. 5 Visit the homepage once, refresh this page — you should see your own visit logged.

Internal log only — entries never leave your gist. Auto-trims to the last 5,000 entries (FIFO) so the file stays small forever.
