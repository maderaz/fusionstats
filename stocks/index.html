How stock vaults are found

A vault counts as a stock vault when its underlying token address carries the tokenised-equity prefix, so a new one appears here automatically. Matching on the vault name would wrongly pull in the cbXRP, USDC and WETH carry vaults, which are not equities. Vaults deployed but never funded stay listed with zero values.
