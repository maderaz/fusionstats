# Token marks

The underlying tokens' logos shown in the site's dropdowns (`/fusion-select.js`,
`data-token`), served from our own origin like the network marks in
`/icons/chains`, so a filter never waits on, or breaks with, someone else's CDN.
All unmodified but xaut.svg, recoloured as noted.

| file | source | token |
| --- | --- | --- |
| btc.svg | web3icons `raw-svgs/tokens/branded/BTC.svg` | BTC, BTC.b |
| cbeth.svg | web3icons `CBETH.svg` | cbETH |
| crv.svg | web3icons `CRV.svg` | CRV, cyCRV (CurveYield's CRV: no mark of its own in either set) |
| crvusd.svg | web3icons `CRVUSD.svg` | crvUSD |
| dai.svg | web3icons `DAI.svg` | DAI |
| eth.svg | web3icons `ETH.svg` | ETH |
| eurc.svg | web3icons `EURC.svg` | EURC |
| pol.svg | web3icons `POL.svg` | POL |
| pyusd.svg | web3icons `PYUSD.svg` | PYUSD |
| reth.svg | web3icons `RETH.svg` | rETH |
| usdc.svg | web3icons `USDC.svg` | USDC |
| usde.svg | web3icons `USDE.svg` | USDe |
| usdt.svg | web3icons `USDT.svg` | USDT, USDT0 |
| xaut.svg | web3icons `raw-svgs/tokens/mono/XAUT.svg`, filled Tether Gold's `#DDA85B` (the branded one is white, for dark backgrounds) | XAUt, XAUt0 |
| cbbtc.svg | SmolDapp tokenAssets `tokens/1/0xcbb7…33bf/logo.svg` | cbBTC |
| steth.svg | SmolDapp `tokens/1/0xae7a…fe84/logo.svg` | stETH |
| usdg.svg | SmolDapp `tokens/1/0xe343…491d/logo.svg` | USDG |
| wbtc.svg | SmolDapp `tokens/1/0x2260…c599/logo.svg` | WBTC (web3icons' is white, for dark backgrounds) |
| weeth.svg | SmolDapp `tokens/1/0xcd5f…b7ee/logo.svg` | weETH |
| weth.svg | SmolDapp `tokens/1/0xc02a…6cc2/logo.svg` | WETH |
| wsteth.svg | SmolDapp `tokens/1/0x7f39…2ca0/logo.svg` | wstETH |

The tokenised stocks use their own marks in `/stocks/icons`. A token with no
mark here gets a lettered badge; add its file and its symbol in `TOKENS` in
`/fusion-select.js` to show the real one.
